## Checkpoint 0: environment survey (before any code)

**Findings that shaped the design:**
- The Hugging Face dataset holds **386 JPEGs, not 408**: 22 slides listed in `CLWD.csv` are
  missing. Six patients have no available slide at all and must be excluded, which leaves
  **203 usable patients**. The file list (with sizes and sha256) is frozen in `data/hf_file_manifest.csv`.
- The JPEGs are 0.2-1.6 GB each (413 GB in total). One slide per patient still means **~218 GB**,
  so extraction has to stream: download → decode → embed → delete, one slide at a time.
- The HF release ships a richer `CLWD.csv` (13 columns). Its labels are identical to the
  brief's file (verified row by row). Its `Multi_Subtypes` column, which lists every pattern
  the pathologist saw, is kept for error analysis.
- Access available from the build container: HF metadata yes; HF image CDN no (blocked);
  no GPU. So stage 1 and the real runs go in Kaggle notebooks, and this container tests
  everything else on synthetic features.

## Checkpoint 1: scaffold, data stage, all modules (commit `c1f20f9`)

**Built**
- `conf/default.yaml` with a typed loader (`src/pathfusion/config.py`) that rejects unknown keys
  and takes dotted CLI overrides.
- **Data** (`data/metadata.py`, `data/splits.py`, `scripts/00_prepare_data.py`):
  - one slide per patient, using the lowest *available* `WSI_ID`
  - quirk 1 (ID 8377886): merged into one patient
  - quirk 2 (5 conflicting patients): label taken from the selected slide
  - quirk 3 (missing slides): affected patients excluded
  - The alternatives (`split`, `exclude`, `majority`) are config switches.
  - Per-class stratified 70/10/20 split → **140/22/41**, every class in every split. The split
    and the 5-fold development CV folds are committed with sha256 checksums, verified on every load.
  - `artifacts/data/data_audit.md` and `docs/DATA_DECISIONS.md` explain each choice.
- **Tiling** (`data/tiling.py`):
  - JPEG shrink-on-load straight to 20x (libvips, with a Pillow `draft` fallback)
  - HSV-saturation Otsu tissue mask with pen-ink and dark-artefact removal
  - 224 px tiles at stride 224, kept if ≥50% tissue, seeded cap of 4096 per slide
  - QC overlay image per slide
- **Encoders** (`embeddings/uni2h.py`, `virchow2.py`, `phikonv2.py`): one module per model.
  Preprocessing is read from each model's own config, and normalisation runs on the GPU.
  Virchow2 uses CLS ⊕ mean patch tokens (2560-d), following its model card.
- **Extraction** (`embeddings/extract.py`, `scripts/01_extract_embeddings.py`):
  - single pass, all 3 models on identical tiles
  - prefetches the next slide while the current one is processed
  - atomic `.h5` writes, resume, sharding
  - per-model GPU time via CUDA events, a timing manifest, and a summary
- **MIL + fusion** (`models/mil.py`, `fusion/*`):
  - gated ABMIL with masked padding
  - early concat (none/L2/z-score, optional PCA)
  - late fusion (mean, logit mean, out-of-fold weighted vote, out-of-fold stacking)
  - intermediate multi-stream fusion (gate, attention, concat, with modality dropout)
  - all registered by family name behind one `FusionSpec`
- **Agent** (`agent/*`):
  - 3 single-model references and 8 fixed coverage trials, then adaptive proposals
  - proposers: deterministic hill-climb, or an LLM (local Qwen on Kaggle GPU, or any
    OpenAI-compatible API), validated and de-duplicated, falling back to deterministic
  - 5-fold dev CV with Nadeau–Bengio-corrected paired SE and a noise-aware acceptance rule
  - budget, patience, one-SE final pick, bootstrap winner's-curse optimism
  - `decisions.jsonl`/`.md` log
- **Evaluation** (`eval/*`, `scripts/03_final_evaluation.py`):
  - the brief's six table rows with an identical recipe, 5 seeds each
  - stratified patient bootstrap CIs and paired bootstrap differences
  - per-class AUROC, confusion matrices, an error analysis against `Multi_Subtypes`
  - figures, and `TEST_LOCK.json` (test is evaluated once)
- Kaggle notebooks (generated by `scripts/make_notebooks.py`), README, `.gitignore`.

**Verified:** data/tiling/metrics tests (21) passed.

## Checkpoint 2: full test suite, two bug fixes, end-to-end smoke run

**Bugs found by the tests and fixed**
1. *Non-deterministic training.* Network weights were initialised before the seed was set,
   so two runs with the same seed differed. Now `torch.manual_seed(seed)` runs before the model
   is built, and the test `test_training_is_seed_deterministic` guards it.
2. *Deterministic fallback stopping too early.* When its top anchors were single-model
   references, the hill-climber found no fusion neighbours and stopped. It now anchors only on
   fusion trials (up to 4 distinct ones).
3. Patience no longer counts the fixed coverage trials. Otherwise the agent could stop right
   after the coverage phase without ever adapting.

**Verified**
- `pytest`: **50 passed** (≈1 min, CPU). Coverage:
  - split leakage, reproducibility and checksum; the quirk policies
  - tiling on synthetic slides with pen ink, and 1/4-scale JPEG decoding
  - extraction with stand-in encoders, including resume
  - padding invariance of the MIL networks; every fusion pipeline fits and predicts
  - seed determinism
  - LLM proposer: valid, invalid, duplicate, early-stop and outage paths (scripted fake LLM)
  - winner's-curse optimism > 0 on pure-noise trials
  - a full agent run that never sees test patients
- `scripts/smoke_e2e.py`: stage 2 → 3 → 4 through the real CLI on synthetic features in a
  temp directory. All 10 expected outputs are produced, and **a second stage-3 run is refused
  by the test lock**. The synthetic numbers check the plumbing only and are not results.
- `ruff`: clean. Figures inspected visually (forest plot, curves, confusion, trajectory).
- `requirements.txt` pinned to the tested versions; `requirements-extract.txt` /
  `requirements-kaggle.txt` hold the stage-1 and Kaggle extras (versions checked on PyPI).
